# 分析プロトコル

## 目的

人物評を直接書かず、観測から反証可能なClaimと条件付きPatternを作る。

## 手順

1. Sourceの同意範囲とlocatorを確認する。
2. 具体的な出来事をEventへ分解する。
3. 原文、観測事実、推論を分離する。
4. appraisal / drive / emotion / action / outcomeの候補をClaimとして書く。
5. Claimごとに最低2件の代替説明を置く。
6. counterevidenceを探す。見つからない場合も空欄の理由を本文に記す。
7. 複数Eventを横断し、条件・文脈・時点が再現する場合だけPattern候補を作る。
8. Traitへ自動昇格しない。context-boundまたはtrait-candidateに留める。
9. validatorとauditを実行する。
10. 次に識別力が高い観測・質問をaudit出力へ残す。

## 中心問い

> この状況で、何を守り、何を得て、何を避けるために、この行動が本人にとって合理的になったのか。

## 禁止

- 単一行動から動機を断定する。
- 行動ログを正式尺度得点へ変換する。
- 回答停止、長文、削除を感情へ直接対応づける。
- 矛盾する欲求を一方に統合する。
- 診断名・人格タイプを結論にする。
